# 12. Glossary

| Term | Meaning |
|---|---|
| Liste / list | Named grocery list shared by its members |
| Artikel / item | One free-text line, open or checked („Im Wagen“) |
| Mitglied / member | User with access; all members have equal rights |
| Teilen-Link / share link | `/j/{token}`; joining requires an account |
| Revision | Per-list counter that changes on every list or item change; the ETag of the item snapshot |
| BFF | Backend-for-frontend: the backend part that does the OIDC login and holds the session |
| IdP | Identity provider (Keycloak) |
